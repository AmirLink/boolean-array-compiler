# Компилятор языка операций над булевскими массивами

Учебный проект: компилятор (транслятор) простого предметно-ориентированного языка для работы с 8-битными булевскими массивами. Реализует полный цикл: синтаксический анализ через конечный автомат, построение таблицы символов, вычисление значений и вывод результата.

## Описание языка

Язык оперирует двумя типами идентификаторов:
- **Пара букв** (например, `AY`) — массив из 8 булевских значений (0/1)
- **Буква + цифра** (например, `X1`) — простая переменная с целочисленным значением

Поддерживаемые операции над кодом:
- `!` — количество единиц в коде
- `%` — разность между числом единиц и числом нулей
- `-` — перевод двоичного кода в десятичное число

### Пример программы

Язык не допускает пробелов — первый встреченный пробел трактуется как конец программы:

```
AY:=10010110;X1:=!10100100;X2:=%10001001;X3:=-AY;
```

Результат выполнения:
```
AY = 10010110
X1 = 3
X2 = -2
X3 = 150
```

## Как это устроено

1. **`syntaxix()`** — конечный автомат (реализован через `switch` по состояниям) проверяет синтаксис строки посимвольно. При ошибке выводит позицию символа стрелкой `^` и текстовое описание, что ожидалось
2. **`memory()`** — разбирает строку на отдельные операторы и строит таблицу символов (односвязный список)
3. **`calculate()`** — вычисляет значения переменных согласно семантике языка, обрабатывает ссылки на другие переменные и сообщает об неопределённых идентификаторах
4. **`show()`** — выводит итоговые значения всех переменных в порядке объявления

## Обработка ошибок

Компилятор различает два типа ошибок:

**Синтаксическая ошибка** — некорректная структура выражения:
```
Вход:  AY := 10010110;X1 := !10130100;...
Выход: AY:=10010110;X1:=!1013
                          ^
                          |
       Ожидалось, что будет последовательность из восьми цифр 0-1
```

**Логическая (семантическая) ошибка** — использование неопределённой переменной:
```
Вход:  ...X3 := -AX;   (AX нигде не объявлена)
Выход: ОШИБКА: Переменная 'AX' не определена
```

## Сборка и запуск

```bash
g++ -std=c++17 -o compiler compiler.cpp
./compiler
```

Программа читает входные данные из `txt.txt` в рабочей директории и записывает результат в `itog.txt`.

## Примеры

В папке `examples/` — три готовых сценария:

| Файл | Сценарий |
|---|---|
| `txt.txt` | Успешная компиляция |
| `txt_syntax_error.txt` | Синтаксическая ошибка (некорректный код) |
| `txt_logic_error.txt` | Логическая ошибка (неопределённая переменная) |

Чтобы попробовать любой из них:
```bash
cp examples/txt_syntax_error.txt txt.txt
./compiler
cat itog.txt
```

## Стек

C++17, стандартная библиотека (`<iostream>`, `<fstream>`, `<string>`, `<cstring>`), без внешних зависимостей.

## Примечание

Оригинальная версия использовала `strcpy_s` (расширение MSVC) — в этой версии заменено на портируемый `strcpy` для сборки под GCC/Clang на Linux/macOS.
